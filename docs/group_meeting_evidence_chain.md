# 组会证据链与事实清单（初稿）

> 用途：下周三课题组组会汇报底稿。数据来自当前运行时状态文件与两轮轮次报告，物理结论仍需在组会前由导师/领域专家核对。

## 1. 一句话结论

两轮真实实验均表明，在“固定线性模型 + 固定窗口”的消融框架下，加上 `p2_y中心值` 没有带来正增益。该结果只否定“当前模型族与窗口下存在独立预测增量”，不能直接否定日影南北偏移的物理信息价值。

## 2. 两轮闭环证据链

### 第 1 轮：`E_R01_03`

| 项目 | 内容 |
| --- | --- |
| 要回答的问题 | 日影南北偏移在已有物理变量基础上是否带来太阳风速度预测增量 |
| 对照组 | `photosphere + BY` |
| 实验组 | 对照组 + `p2_y中心值` |
| 窗口 | 滞后 3 天，预测超前 3 天，训练窗口 14 天 |
| 结果 | RMSE `52.23 → 53.57`；Pearson `0.3978 → 0.3317`；ΔPearson `-0.0661` |
| 假设影响 | H1、H2、H5 支持度下降 |
| 本轮结论 | 当前线性、固定窗口下未观察到独立增量；不能确认机制假设，也不能完全排除 |
| 已知问题 | 协议承诺的稳健性诊断未完整执行；下一轮建议未生成 |

### 第 2 轮：`E_R02_03`

| 项目 | 内容 |
| --- | --- |
| 要回答的问题 | 更换时间尺度与更完整的对照变量后，日影偏移是否仍有增量 |
| 对照组 | 常规日地环境变量 + 误差项 + Kp |
| 实验组 | 对照组 + `p2_y中心值` |
| 窗口 | 滞后 7 天，预测超前 5 天，训练窗口 21 天 |
| 结果 | RMSE `87.16 → 88.18`；Pearson `0.1195 → 0.1125`；ΔPearson `-0.0071` |
| 假设影响 | H4、H6 支持度下降并进入剪枝/观察 |
| 本轮结论 | 更换窗口与对照组后仍无正增益；但实验无法真正区分 H4 与 H6 |
| 已知问题 | 两组实验只差是否加入一个特征，没有窗口扫描或误差分层，不能回答“通过哪条机制路径传递” |

### 两轮之间的衔接逻辑

1. 第 1 轮负结果说明：不能停在 3/3/14 天窗口和单一线性消融。
2. 第 2 轮把窗口换到 7/5/21 天、对照组补入更完整的日地环境变量，仍然负增益。
3. 到第 2 轮为止得出的诚实结论是：日影偏移的“独立线性增量”在当前数据口径下不显著；但“非线性机制”和“条件效应”尚未检验。
4. 下一轮应有明确方向：滞后/超前网格扫描、太阳风状态分层、非线性基线模型、误差高低分组。

## 3. 组会汇报三段主线

1. **为什么值得做**：LHAASO 日影能提前感知行星际磁场信息，传统人工穷举无法覆盖高维时滞组合。
2. **系统如何工作**：假设树是状态机，不确定性驱动实验设计，真实结果回写假设空间，人工 PI 保留决策权。
3. **真实反馈与下一步**：展示两轮负结果如何逐步收窄结论，并明确下一个待检验的科学问题。
