## 2. 五个验收问题的结论

### Q1 LHAASO 日影领先约 3.3 天，具体对应什么观测量？— 通过

- 本地文献命中：“Compared with the near-Earth spacecraft, the Sun's shadow can provide 3.3-day earlier predictions for the IMF”。
- 远端命中：日影测量磁场约比 1AU 卫星提前 1.8 天（与 ARGO-YBJ 的 1.6 天一致）。
- 结论：对应的是**行星际磁场（IMF）测量/预测的时间提前量**；未出现“太阳风速度已能提前 3.3 天准确预报”的越界改写。

### Q2 这篇论文是否证明日影能提高太阳风速度预测？— 通过但需保留边界

- 远端原文只支持：日影测量的磁场比卫星提前 1.8 天，对“CHH 引发地磁暴”的预报存在时间优势；未来可预报 CHH 与 CME。
- 未检出“已证明提高太阳风速度预报准确率”的表述。
- 结论：论文证明的是**同磁场量的早到能力**，不是太阳风速度数值预报精度；是否提升本项目预测精度仍需实验判定，答辩时应明确这一边界。

### Q3 什么证据支持本轮某条假设？— 有条件通过，不能自动当证据

- 远端命中通用磁场模型（PFSS/CSSS）片段和参考文献列表，但**没有命中能直接支持某条具体项目假设的实验证据**。
- 结论：命中片段只能作为背景/间接依据，必须由人做相关性判定，并按“直接证据、间接依据、物理推测”分类；程序不得把任意命中自动加为假设支持。

### Q4 知识库未覆盖的问题 — 未通过，需要显式无证据处理

- 查询“量子引力对地磁暴预报的约束是什么”时，本地无命中，远端仍返回 3 条常规地磁暴/日影片段，未返回“未找到足够依据”。
- 结论：当前远端检索没有显式的低相关拒答机制；对知识库未覆盖的问题，对话层必须强制输出“未找到足够依据”，禁止把通用命中当作答案。

### Q5 RAG 片段能否进入生成链路 — 部分通过，链条有明确边界

- 已验证：RAG 片段进入“假设提出者”的 prompt，2 条 `rag_notes` 可见。

- 若严格验收“某条 RAG 结果直接驱动候选实验”，需要补齐该注入或明确把它定义为两段式间接链路；本轮不做功能扩展，保留此限制。

## 3. 必须保留的约束

1. **文献依据与实验支持分开**：检索到相关论文不代表本项目的假设已获实验验证；同一论文的多个片段不算多份独立证据。
2. **证据只记一次**：RAG 命中只作为假设来源/背景，不进入实验支持度，不重复加分。
3. **缓存防串**：更换知识库或启动新会话后，应确认 `upload_manifest.json`、`rag_notes` 与当前会话根一致，避免复用旧的无文献生成结果。
4. **新会话需重新带文献**：本次验收的临时会话不会保留给正式闭环；正式启动时通过 `knowledge_files` 上传上述 4 份 txt，确保 `outputs/pdf_texts/` 与 `upload_manifest.json` 属于该会话。
