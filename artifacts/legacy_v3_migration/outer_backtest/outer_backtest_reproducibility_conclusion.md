## 可表述的答辩口径

> 在冻结的迭代评估段中，双方向日影方案出现一次小幅 RMSE 改善；预登记的早段补充回测中，同一设置的两个窗口均未复现该改善，且两个窗口各出现了一个方向相反、未做多重比较调整的不跨零结果。因此该发现当前应表述为局部、待重复，不能表述为稳定的跨时段增量。

## 边界

- 这是补充时间回测，不是独立盲测：特征定义、网格、基线、提前期与分类规则仍来自 dev 段探索。
- mag_both 仅表示未复现 dev 中的不跨零改善，不能宣称跨时段稳定，也不能宣称已证伪日影物理作用。
- f1/f2 各有真实日历缺失，共同样本分别降为 17 天与 23 天；缺口已保留在 window_coverage 中。
- 24 组比较未做多重比较调整；两个额外不跨零结果方向相反，应视为探索性信息。
- stable_rmse=true 只表示该窗口内的块 bootstrap 区间未跨零，不等同于科学意义上的稳定性验证通过。
- 未测量的 Pearson 不填零，仍遵循未计算/不可计算规则。
