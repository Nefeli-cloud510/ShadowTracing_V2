# v4 平坦预测独立诊断（修订版）

## 任务与数据

- 数据：`OMNI_2021 + LHAASO 日影`，完整 196 天日历，目标 `SW Plasma Speed, km/s`。
- 预测：`issue_date + 3 日历天`；特征均在发布日可得。
- 日期口径：报告中的开发评估段写在发布日，为 `2021-08-26` 至 `2021-09-29`；对应目标日为 `2021-08-29` 至 `2021-10-02`。
- 共同样本：158 个（A 单独 177、B 单独 173、C 158；为三方案可比取交集），训练 120、dev backtest 35。
- 评估段只称为 `dev_backtest`，不称为独立盲测。
- Ridge / ElasticNet 使用相同冻结日历折，训练段内对等网格选参；另加无惩罚 LinearRegression 参照。
- 每次报告均包含 RMSE、MAE、Pearson r、R²、预测标准差。

## 三方案

- A：最近 3 个日历日风速 `vsw_lag0/lag1/lag2`。
- B：A + 过去 7 天均值、标准差、线性趋势。
- C：A + `target_date - 27 天` 风速（发布日即可得，对应太阳自转重现信息）。
- 日影臂：对应方案特征 + `shadow_lag0/lag1/lag2`。

## 选参结果（共同日历折，训练内搜索）

| 模型 | A/B/C 基线 | A/B/C 加日影 |
|---|---|---|
| Ridge | alpha＝10 | alpha＝100 |
| ElasticNet | alpha＝1，l1_ratio＝0.90 | alpha＝1，l1_ratio＝0.01 |

l1 网格已补 `0.01 / 0.99` 作边界敏感性：基线不再落在 0.9 边缘，日影臂仍会选到 0.01 端点，因此 Enet 日影臂保留 `boundary_hit=True`，这是 l1 网格端点命中，不是求解失败。

## 为什么预测“平”

1. 在当前样本、特征构造和线性模型范围内，预测解释力有限；单纯减弱正则化没有带来训练内验证改善。
2. 训练段真实风速标准差约 `67.8 km/s`，最佳模型预测标准差约 `15–25 km/s`；35 天 dev 段真实值标准差 `50.3 km/s`，Ridge/ElasticNet 预测标准差约 `10.4–15.2 km/s`。
3. Ridge 在 `alpha≈10–100` 最优，降到 `0.01` 以下训练内验证变差；ElasticNet 网格最优为 `alpha≈1`。
4. 无惩罚 LinearRegression 预测波动最大，但 dev RMSE 普遍更差。
5. 因此目前只能说明这些模型没有获得好的短期波动追踪能力，不能据此认定所有模型或所有物理信息都不可预测。

## 修正后的折内验证（只拟合 train_index，再评价 eval_index）

| 模型 | A 基线 CV RMSE | C 基线 CV RMSE | C＋日影 CV RMSE |
|---|---:|---:|---:|
| Ridge | 59.20 | 55.47 | 57.58 |
| ElasticNet | 58.91 | 55.10 | 57.50 |

结论：

- 27 天重现信息稳定改善训练内基线，C 的优先级有依据，不是只看 dev 更好。
- 在 C 基线上加入日影，训练内验证反而变差；dev 上改善，两侧证据不一致。
- 下一轮应检验：日影在包含重现信息的基线之外，是否存在跨时间可重复的增量。

## dev_backtest 简单基线（n=35，发布日 8/26–9/29）

| 对照 | RMSE, km/s | Pearson r |
|---|---:|---:|
| 训练均值 | 50.68 | N/A：常数预测 |
| 最新风速持续性 | 59.98 | 0.216 |
| A 风速历史 Ridge 基线 | 50.84 | 0.113 |
| A＋日影 Ridge | 49.11 | 0.233 |
| C 历史＋27天重现 Ridge 基线 | 49.71 | 0.205 |
| C＋日影 Ridge | 48.41 | 0.282 |

常数预测不再输出伪 r≈0，而是明确的 `constant_prediction`。

## A/B/C 日影增益（同一共同样本与折）

| 方案 | 模型 | RMSE 增益 | 95% CI | Pearson 增益 | 95% CI | 稳定 |
|---|---:|---:|---:|---:|---:|:--:|
| A | Ridge | +1.73 | [-1.02, 4.57] | +0.120 | [-0.306, 0.453] | 否 |
| A | ElasticNet | +1.41 | [-1.01, 3.84] | +0.115 | [-0.309, 0.469] | 否 |
| B | Ridge | +2.72 | [-0.69, 6.80] | +0.171 | [-0.292, 0.490] | 否 |
| B | ElasticNet | +1.76 | [-0.90, 4.95] | +0.136 | [-0.313, 0.467] | 否 |
| C | Ridge | +1.30 | [-1.42, 3.61] | +0.077 | [-0.288, 0.343] | 否 |

正值表示日影臂更优；点估计全部正向，但 95% CI 全部跨零，结论为“未检出稳定增益”。

## 结论与下一步

1. 停止继续大范围搜索 alpha；网格边界敏感性已做完，继续扩网格预期收益很小。
2. B 方案日影增益最大，但绝对 RMSE 不比 A 好，暂不优先。
3. 保留 A 作参照，将 C 作为更合理的候选基线。
4. 下一步优先做外层时间泛化：预先固定外层回测，在每个外层训练段内部选参；现有 35 天只能作为开发评估，不能新增独立证据。
5. 本轮探索作为闭环动机的表述：预测平坦不是单纯过强正则化；重现信息改善基线，但日影增量在训练内验证与开发评估之间不一致，因此下一轮优先检验时间泛化。

- `parameter_curves_elasticnet_l1.png`：ElasticNet 按 l1_ratio 分面的参数曲线，不再跨 l1 求平均冒充实际选参曲线。

- `coefficients.csv`：每个 run 的最终系数与截距。
- `daily_predictions.csv`：35 天逐日发布日/目标日/预测。
- `simple_baselines.csv`：训练均值（常数预测，Pearson=N/A）、持续性基线。
- `eval_comparison.csv`、`gain_ci.csv`、`gain_ci.png`：RMSE/Pearson 增益与 95% CI。
- `manifest.json`：数据指纹、冻结划分、日期口径、bootstrap 参数和结论提示。
