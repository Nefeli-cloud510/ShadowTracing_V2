# v4 平坦预测独立诊断（不触碰闭环保留状态）

## 任务与数据

- 数据：`OMNI_2021 + LHAASO 日影`，完整 196 天日历，目标 `SW Plasma Speed, km/s`。
- 预测：`issue_date + 3 日历天`；特征均在发报日可得。
- 划分：共同样本 158 个（A 单独 177、B 173、C 158；为三方案可比统一取交集），训练 120、dev backtest 35。
- 评估段：`2021-08-26` 至 `2021-09-29`，连续 35 天，只称为 `dev_backtest`，不称为独立盲测。
- 方法：Ridge / ElasticNet 使用相同冻结日历折，在训练段内对等网格选参；另加无惩罚 LinearRegression 参照。
- 每次报告均包含 RMSE、MAE、Pearson r、R²、预测标准差，不只给 RMSE。

## 三方案说明

- A：最近 3 个日历日风速 `vsw_lag0/lag1/lag2`。
- B：A + 过去 7 天均值、标准差、线性趋势。
- C：A + `target_date - 27 天` 风速（发报日可用，对应太阳自转重现信息）。
- 日影臂：对应方案特征 + `shadow_lag0/lag1/lag2`。

## 为什么预测“平”

1. 所有模型的显著共同点不是 alpha 太高，而是输入信息本身对下一风向量的解释力有限。
2. 训练段真实风速标准差约 67.8 km/s，最佳模型预测标准差只有约 15–25 km/s；35 天 dev 段真实标准差 50.3 km/s，Ridge/ElasticNet 预测标准差约 10.5–15.2 km/s。
3. 弱正则化只让训练拟合更“活泼”，没有形成稳定的训练内验证收益：
   - Ridge：`alpha=0.0001~0.001` 时训练内验证 RMSE 仍最高；最优落在 `alpha≈10–100`。
   - ElasticNet：网格最优多为 `alpha≈1`；继续降到 `0.01` 以下，训练内验证变差。
   - LinearRegression 预测标准差最大，但 dev RMSE 反而普遍比有惩罚模型更差。
4. 因此**不能通过继续调小 alpha 让“dev 预测曲线更像真实值”**；这是过拟合/信息不足区，不是单纯欠拟合。

## dev_backtest 绝对表现与简单基线（n=35）

| 对照 | RMSE, km/s | Pearson r |
|---|---:|---:|
| 训练均值 | 50.68 | ≈0.00 |
| 最新风速持续性 | 59.98 | 0.216 |
| A 风速历史（Ridge 基线） | 50.84 | 0.113 |
| A 风速历史+日影（Ridge） | 49.11 | 0.233 |
| C 历史+27天重现（Ridge 基线） | 49.71 | 0.205 |
| C 历史+27天重现+日影（Ridge） | 48.41 | 0.282 |

## 结论

1. 当前近似常数预测主要来自**单日点输入的低解释力**，不是单纯 alpha 过大；扩展低正则化网格不会解决。
2. C 方案（27 天重现信息）是唯一同时降低基线和日影臂 RMSE、并明显提高 Pearson r 的方向；但它仍是 dev_backtest 上的探索性收益，不是已验证增益。
3. B 方案（7 天统计形态）对基线帮助不明确，dev RMSE 没有稳定优于 A，暂不优先推进。
4. 下一步最值得做的实验是：**固定共同样本与折，把 C 历史（含 27 天重现）作为新基线，再做一次与日影的完整配对对比**；同时保留 A 作为参照，避免把“历史信息变强”误读成“日影有效”。
5. 35 天区间已反复查看，任何后续成绩都只能作为开发评估和进一步实验选择的依据。
